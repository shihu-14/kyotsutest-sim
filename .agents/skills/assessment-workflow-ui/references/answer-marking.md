# Answer Marking

Answer marking should be predictable and reversible unless the assessment rules
say otherwise.

- Show available choices in the expected order for the assessment.
- Enforce single-choice or multi-choice rules in the data model, not only in
  visuals.
- Keep the mark color and shape consistent across taking, scoring, and review
  modes.
- For correct-answer overlays, layer marks intentionally so the user's answer
  remains understandable.
- Make unanswered state explicit in scoring and review.
- Ensure cover or instruction page mark areas follow the same interaction rules
  if they are real answer fields.

Verify by clicking the first, middle, last, and zero or special-choice positions
when present.
