# Timer And Page Navigation

Timed assessment controls must avoid accidental exits.

- Keep timer status visually separate from finish and home actions.
- Label finish actions by outcome, for example "Proceed to scoring" rather than
  a vague exit label.
- Confirm actions that end or abandon the attempt when answers would be lost.
- Keep page controls stable in width so selected pages do not shift the whole
  bar.
- For long page lists, scroll the selected page into view predictably when
  moving with side arrows.
- Hide previous or next arrows at document edges if that is the chosen pattern.

Verify first page, last page, cover page, and overflow page-list navigation.
