# Web UI Design System

Design the usable screen first. Do not make a landing page or decorative
wrapper unless the task asks for one.

## Workflow

1. Identify the primary user task, secondary task, and destructive exits.
2. Define the information hierarchy before adjusting color or ornament.
3. Choose controls by function: tabs for views, segmented controls for modes,
   toggles for binary settings, sliders or inputs for numeric values, and menus
   for option sets.
4. Keep repeated items consistent in size, alignment, and interaction states.
5. Verify responsive behavior and text fit at likely viewport sizes.
6. For design candidates, vary layout model, density, navigation, information
   grouping, and interaction pattern before varying color.
