# Accessibility

Use accessibility checks as design constraints.

- Use semantic buttons and inputs for interactive elements.
- Provide visible focus states.
- Ensure icon-only controls have accessible names.
- Do not rely on color alone for correctness, errors, selected state, or
  destructive actions.
- Keep text contrast sufficient for normal and disabled states.
- Make dialogs dismissible by the intended controls and, when appropriate, by
  clicking outside or pressing Escape.
- Preserve keyboard reachability for navigation and answer controls.
