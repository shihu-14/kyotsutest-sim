# Forms And Controls

Match control shape to user intent.

- Buttons execute commands.
- Icon buttons need accessible labels or clear visible text nearby.
- Toggles represent on/off settings.
- Checkboxes represent independent selections.
- Radio groups represent exactly one choice from a small set.
- Segmented controls switch mode within the current surface.
- Tabs switch major views.
- Sliders work for approximate numeric values; inputs work for exact values.
- Menus work for larger option sets or secondary commands.

Keep button labels action-oriented. Avoid vague labels when the consequence is
large; confirmation dialogs should name the actual action.
