# Layout

Start with the work surface.

- Put the primary task in the most stable, central, or widest region.
- Put reference panels, navigation, and secondary controls around it.
- Avoid nested cards. Use cards for repeated items, modals, or framed tools.
- Align related controls on the same axis and keep action groups visually close.
- Reserve large type and large empty space for true hero or overview screens.
- For dense tools, prefer compact bands, sidebars, and predictable panels.

Good candidate sets should differ by structure: split-pane, command bar,
sidebar, inspector, canvas-first, table-first, wizard, dashboard, document-first,
or compact console.
