# Responsive

Responsive design should preserve the task, not just shrink the desktop.

- Define stable dimensions for fixed-format surfaces such as boards, page
  controls, timers, grids, and document previews.
- Let text wrap before it overflows; avoid viewport-width font scaling.
- On narrow screens, collapse secondary panels below or behind a clear control.
- Preserve primary actions without forcing horizontal scrolling of the whole
  page.
- Test the smallest expected width and a normal desktop width.
- Watch for scrollbars, clipped controls, overlapping text, and shifting button
  sizes.
