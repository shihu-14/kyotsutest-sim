# Visual Hierarchy

Hierarchy comes from content order, size, weight, spacing, and contrast.

- Make the most important value or task easiest to find without scanning.
- Use restrained color for state and action, not as the only structural cue.
- Keep typographic scale proportional to the container size.
- Avoid one-note palettes where every surface is the same hue family.
- Keep repeated item metadata compact and aligned.
- Prefer real content, generated bitmap images, or actual product/document
  previews over abstract decorative shapes when inspection matters.

When generating design options, ensure each option changes at least one major
dimension: layout, navigation model, density, panel grouping, or interaction
flow.
