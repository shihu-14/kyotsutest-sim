# 共通テスト形式模試 シミュレータ

Texコードで書かれた自作の共通テスト形式の問題をブラウザ上で解くことができるシミュレータ．

## 主な機能

- 問題冊子をページ送りやページジャンプできる機能．
- 問題冊子上のマークとマークシートの解答状態を同期する．
- 単一選択と複数選択の問題に対応．
- 問題冊子を拡大・縮小して表示できる機能
- 制限時間を表示し，時間切れになると自動的に採点へ進む．
- 採点時に正誤を問題冊子上へ順番に表示する．
- 採点後に得点を表示し，復習画面で正解を確認できる．
- ホーム画面では鉛筆と消しゴムを使って書き込みができる．

## 今後の実装予定

- ホーム画面から利用できる作問エディタ．
- LaTeX形式の問題文の編集・プレビュー．

## 使用技術

- React / TypeScript
- Vite
- KaTeX
- Vitest

## 起動方法

Node.js 20.19.0以降の20系，22.13.0以降の22系，または24系以降が必要です（Node.js 22 LTS推奨）．

依存パッケージをインストールする．

```bash
npm install
```

開発サーバーを起動する．

```bash
npm run dev
```

ターミナルに表示されたURLをブラウザで開く．

## 検証

PR前の型チェック，lint，format check，テスト，ビルドをまとめて実行する．

```bash
npm run check
```

coverageを確認する．

```bash
npm run test:coverage
```
