# 共通テスト形式 ウェブ模試システム

`spec.md` の要件に合わせた、共通テスト形式の受験・採点・復習・作問エディタを備える React/Vite アプリです。

## 採用技術

- Vite + React + TypeScript: 受験画面とマークシートを低遅延で同期するためのSPA構成
- KaTeX: 数式の高速レンダリング
- Monaco Editor: ブラウザ内 LaTeX 作問エディタ
- localStorage: オフライン環境での解答保持と作問ソース保持
- Vitest + Testing Library: 採点ロジック、LaTeX解析、マークシート操作の検証

## 機能

- 公開試験一覧、表紙、試験開始
- 問題冊子のページ送りとページジャンプ
- 問題文側とマークシート側の双方向マーク同期
- 単一選択と複数選択のクリック反転
- 制限時間タイマーと時間切れ自動採点
- 赤ペン風の自動採点アニメーションと得点カウントアップ
- 復習モードでの正解選択肢の赤色表示と解説表示
- LaTeX 作問エディタ、リアルタイムプレビュー、`\mark` コマンド解析
- マークスロット、正解値、配点の JSON プレビュー

## 開発

```bash
npm install
npm run dev
```

## 検証

```bash
npm test
npm run build
```
