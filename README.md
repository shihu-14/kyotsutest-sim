# 共通テスト形式模試 シミュレータ

LaTexで書いた自作の共通テスト形式の問題をブラウザ上で解くことができるシミュレータ．

## 主な機能

- 問題冊子とマークシートを使って解答できる．
- 問題冊子のページ移動や拡大・縮小ができる．
- 問題冊子上のマークとマークシートの解答状態を同期する．
- 制限時間が終了すると自動的に採点へ進む．
- 採点結果を問題冊子上へ順番に表示する．
- 採点後に得点を表示し，復習画面で正解を確認できる．
- ホーム画面では鉛筆と消しゴムを使って書き込みができる．

## 設計・実装のポイント

### PDF上の解答欄をクリック可能にする

TeXから生成したPDFをページごとの画像として表示し，各解答欄について画像上の位置をパーセント座標で定義している．

その座標をもとに，画像の上へ透明なHTMLのボタン要素を重ねることで，PDFの見た目を維持したまま解答欄をクリックできるようにした．

各ボタンには対応する問題と選択肢を関連付け，クリック時に解答データを更新する．問題冊子とマークシートは同じ解答データを参照する構成とし，表示側に個別の解答状態を持たせないようにした．

### 試験の状態遷移をReducerで管理する

試験一覧，表紙，受験，採点，復習という一連の状態を，ReactのReducerパターンを用いて管理している．

現在の状態と発生した操作をReducerへ渡し，次の状態を一箇所で決定する構成とすることで，複数のboolean値を組み合わせて画面状態を管理することを避けた．

例えば，「試験を開始する」という操作では，表紙の状態から受験状態へ遷移すると同時に制限時間を設定し，「採点へ進む」という操作では受験状態から採点状態へ遷移する．このように，画面遷移とそれに伴うデータ更新を同じ状態遷移として扱っている．

### 自動採点と採点アニメーション

採点処理はUIから分離し，各問題について受験者の解答と正解を比較する関数として実装している．

複数選択問題では，選択された値を問題内の選択肢順に正規化してから正解と比較することで，クリックした順序に依存せず正誤を判定する．各問題の判定結果と配点から得点を計算し，その結果を採点画面へ渡している．

○・×の採点表示には画像とSVGマスクを組み合わせている．○では円を描くパス，×では2本の直線パスを用意し，CSSでSVGのストロークを順番に進めることで，赤ペンで実際に書き込んでいるように画像を徐々に表示する．×は1本目を描画した後に2本目を遅延させて描画する構成としている．

### テストと自動検証

採点や状態遷移などのロジックはUIから分離し，単体でテストできるようにしている．また，問題冊子，マークシート，タイマーなどについては，実際のクリックや表示変化を含むコンポーネントテストを行っている．

開発時には以下を自動で確認する．

- TypeScript による型チェック
- ESLint による静的解析
- Prettier によるフォーマット確認
- Vitest によるテスト
- Vite によるビルド

これらを1つのコマンドで実行できるようにし，GitHub ActionsにおいてもPull Requestおよび`main`へのpush時に同じ検証を実行する．

## ファイル構成

```text
.
├── src/
│   ├── assets/
│   │   ├── exams/          # TeXコード，pdfファイル，問題中の画像など
│   │   └── home-tools/     # 鉛筆・消しゴムの画像
│   │
│   ├── components/
│   │   ├── home/           # ホーム画面，注意事項の画面
│   │   ├── exam/           # 問題冊子，マークシート，タイマー
│   │   ├── scoring/        # 採点・復習画面
│   │   └── authoring/      # 作問機能
│   │
│   ├── data/
│   │   └── exams/          # 問題，正解，配点，ページ，マーク位置などの試験データ
│   │
│   ├── hooks/              # 状態管理や，試験中のページ遷移，拡大縮小など
│   ├── utils/              # 採点，保存，描画などのロジック
│   ├── styles/             # 画面ごとのスタイル
│   ├── test/               # テストの共通設定
│   ├── App.tsx             # アプリケーションの画面構成
│   └── types.ts            # 共通の型定義
│
├── .github/workflows/      # GitHub Actions
├── eslint.config.js        # ESLintの設定
├── vite.config.ts          # Vite / Vitestの設定
└── package.json            # 依存関係の管理
```

## 起動方法

Node.js 22 LTSを推奨する．

依存パッケージをインストールする．

```bash
npm install
```

開発サーバーを起動する．

```bash
npm run dev
```

ターミナルに表示されたURLをブラウザで開く．

## 検証

型チェック，lint，format check，テスト，ビルドをまとめて実行する．

```bash
npm run check
```

個別には以下のコマンドを使用できる．

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```
